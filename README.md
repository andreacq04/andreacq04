## 🔥 Proyecto destacado

### CHISPA — Tecnología para conectar con nuestra cultura

**CHISPA** es un proyecto universitario enfocado en conectar a las personas con la cultura local mediante tecnología.

La aplicación integra:

- 🗺️ Mapa de eventos culturales
- 🎭 Directorio de agrupaciones
- 📅 Publicación y consulta de eventos
- 🔐 Registro, inicio de sesión y autenticación
- 🗄️ Base de datos PostgreSQL
- ⚙️ API REST con Node.js y Express
- 🎨 Diseño de interfaz y prototipado en Figma
- 📍 Integración con mapas y ubicación

> Un proyecto donde combino **desarrollo, bases de datos, diseño y cultura**.
